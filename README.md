
# Internet Speedtest Tool

A browser-based speed test measuring download, upload, ping, jitter, and latency.

## Features

- Download speed via Cloudflare Workers
- Upload speed via Cloudflare Workers
- Ping, jitter, latency

## Usage

Click START. App runs tests and shows averages.

## Local Development

Open `index.html` with live server in a browser.

For web deployment, the app uses deployed Cloudflare Workers and is ready to host anywhere.
